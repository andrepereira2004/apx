# Selected outline comparison

Captured only the top 58 logical pixels of the active Hytale display. The
Environments menu was opened for `environments-selected.png`, then closed as
the Media menu opened for `media-selected.png`. The Media menu was closed after
capture. `comparison.png` places the two selected states side by side: left
Environments, right Media. Both use `ButtonOutline` with a 1 logical pixel
selected border and `Appearance.buttonSelectedBorder`. Rounded edges differ
slightly under the active 125% display scale; this is a rasterization effect,
not a different border setting.
