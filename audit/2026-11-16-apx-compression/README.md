# APX compression, launcher actions and battery alerts — 2026-11-16

Owner scope: restyle compression as APX; use only Comprimir for the action/button; include it in future Environments; add Minecraft containers; remove NVIDIA action from Rofi; rename the cycle action to Ir para janela and change its icon; change APX Terminal's Rofi icon; second right-click collapses the action panel; notify below 20% and at 10% battery.

Delivered an unprivileged GTK3 APX compression dialog using the existing font/graphite colors, scoped CSS, native APX folder picker, progress/cancel, filename/format synchronization and destination selection. ZIP, TAR, TAR.gz, TAR.xz, MCWORLD, MCPACK and MCADDON are implemented locally with Python standard-library archives. Mais opções preserves access to the existing File Roller advanced workflow. No API service or user credentials are involved.

Minecraft packaging: a single world/pack folder is flattened so level.dat+db/ or manifest.json is at archive root. Existing ZIPs are repacked rather than embedded inside a second ZIP. MCADDON contains validly rooted MCPACK/MCWORLD containers; selected pack folders are packaged first. Invalid root structures produce an error and no output. This verifies container structure, not NBT/LevelDB/manifest semantic correctness or in-game playability; it does not convert Java worlds. Primary format references: https://learn.microsoft.com/en-us/minecraft/creator/documents/minecraftfileextensions?view=minecraft-bedrock-stable and https://learn.microsoft.com/en-us/minecraft/creator/documents/chunkeroverview?view=minecraft-bedrock-stable .

File integrity: streaming ZIP64, preserved selected directory structure for generic archives, no traversal on repack, no overwrite (renameat2 NOREPLACE), partial-file cleanup and block cancellation. Tested output on the Host-approved FAT USB bridge, including its mapped ownership where chmod is unavailable. The GUI does not modify the input files.
